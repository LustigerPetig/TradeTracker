# Trade Tracker

**Trade Tracker** is a client-side Fabric mod that takes the hassle out of finding the perfect villager trade. Stop clicking through dozens of villagers in your trading hall – just open the tracker, search for what you need, and find the right villager instantly!

##  Features

*    **Smart Search & Filters:** Instantly search for specific items or enchantments. Includes a quick-toggle to only show Enchanted Books.
*   **Advanced Sorting:** Sort all available trades nearby by:
    *   **Distance** (Find the closest villager)
    *   **Cost** (Find the cheapest trade)
    *   **Name** (Alphabetical order)
    *   **Profession**
*    **Live Distance Tracking:** See exactly how far away a villager is. The distance updates in real-time as you walk around!
*    **Flexible View Modes:** Toggle between grouping trades by individual villagers, or viewing a flat, massive list of all available trades nearby.
*    **Villager Highlighting:** Click on a trade in the menu, and the corresponding villager will get a temporary glowing effect so you can spot them immediately in a crowd.
*    **Detailed UI:** Shows villager professions, levels, required workstation icons, and clean scrollable text for long enchantment names.

#  Installation

This is a **Fabric** mod.
To use this mod, you need to install the following into your `.minecraft/mods` folder:

1. [Fabric Loader](https://fabricmc.net/)
2. [Fabric API](https://modrinth.com/mod/fabric-api)
3. **[Cloth Config API (Fabric)](https://modrinth.com/mod/cloth-config)**
4. The latest release of **Trade Tracker**

*(Optional but highly recommended: Install [ModMenu](https://modrinth.com/mod/modmenu) to access the in-game settings!)*

##  How to use
Press `V` in-game to open the Villager Rolodex.
